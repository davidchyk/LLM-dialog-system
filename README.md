# LLM Dialog System

**Author:** Artem Davydchuk

## Overview

LLM Dialog System is a course project dedicated to the development of a software application for dialog interaction with large language models.

The system supports two modes of operation:

* **Web mode** — interaction through a browser-based user interface;
* **CLI mode** — interaction through the command-line interface.

The application is designed to provide convenient chat management, message exchange, and local storage of chat history.

## Main Goals

* provide interaction with a large language model;
* support both web and console interfaces;
* allow users to create and open chats;
* store chat history locally;
* ensure a clear and extensible software architecture.

## Features

* browser-based web interface;
* command-line interface;
* creation of new chats;
* selection of existing chats;
* message exchange in dialogue mode;
* local chat history storage;
* modular project structure for future extension.
